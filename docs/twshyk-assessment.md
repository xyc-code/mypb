# 团委“三会一课”考核

## 页面与接口

登录本地PB后打开：

`http://127.0.0.1:8080/pb/platform/avicit/pb/twshyk/assessment/toManage`

平台菜单可绑定相对地址 `platform/avicit/pb/twshyk/assessment/toManage`。本次新增独立页面入口，没有更改已有菜单、填报表单或权限配置。

所有接口均为GET，使用当前登录组织域，不接受客户端指定组织域或考核日期：

| 地址后缀 | 参数 | 返回 |
| --- | --- | --- |
| `years` | 无 | `data`年份数组、`defaultYear`、`asOfDate` |
| `list` | `year`、`page`（默认1）、`rows`（默认20） | 当前页`data`、`page`、`total`总页数、`records`组织总数及月季/年度起止日期 |
| `detail` | `year`、`leagueId` | `data`单组织数组，包含17个`periods` |

接口前缀为 `platform/avicit/pb/twshyk/assessment/`。成功返回 `flag=success`；无效年份、根节点或不可访问组织返回HTTP 400，查询异常返回HTTP 500。查询不缓存，补录后重新查询即可更新。

列表使用数据库分页，按TREE_SORTS、TREE_SORT、ID稳定排序，仅汇总当前页组织的会议。页码须大于0，rows支持1—100，越界页码回到最后一页；无组织时data为空、records和total为0、page为1。页面默认20条，可选5/10/20/50/100条，支持翻页和输入页码，查询或切换年份回到第一页。表头不提供仅针对当前页的排序。

分页验收：192项DM/MyBatis/服务断言通过，含37组织分20+17条、跨页不重不漏、页码边界和扣分一致；新增30条分页测试组织在事务内回滚，原夹具仍为9组织/54会议。重启Tomcat/Redis后实际浏览器验证每页5条、第二页2条、跳页、切换年份回第一页和第二页17周期明细。平台定制jqGrid默认隐藏分页中心区，已仅在本页恢复显示，无新增前端框架或全局样式修改。

## 时间口径

最新规则（2026-09-17调整）：选择Y年，所有考核统一为Y−1年11月1日至Y年10月31日。月度按自然月，季度为11—1月、2—4月、5—7月、8—10月。支部大会在Y年11月1日起考核，不再按自然年或等到次年1月。区间查询使用开始时间包含、下一周期开始时间不包含，避免丢失月末带时间的会议。

规则卡片按支部大会、支部委员会、团小组会、团课排列；团小组会显示“随时开展，不参与考核”。2026年9月17日完全缺会组织月度扣2.0、季度扣0.6、年度待考核，总扣2.6；10月31日仍为2.8；11月1日起满周期扣3.4。

支部委员会、团课、支部大会各周期至少一次，已结束周期缺会扣0.2分。团小组会不考核；多开不能抵扣其他周期。满周期全部缺会为2.4+0.8+0.2=3.4分。

会议字段为 `DYN_TWSHYK.LEAGUE_ID/HYRQ/HYLX/ORG_IDENTITY`，会议类型使用截图中的中文值。组织使用 `LEAGUE_ORGANIZATION`，排除 `PARENT_ID='-1'`，无会议组织仍参与，不汇总下级，不按有效标志、成立日期减免。

年份仅来自当前组织域的非空HYRQ实际年份，倒序展示。当前年存在时默认当前年，否则默认最大年份；无年份时显示空状态。未来年份若真实存在于会议日期中也会显示，其未到期周期不扣分。

## 本地测试数据

本地原本没有 `DYN_TWSHYK`，现按截图创建29列，包含全部8个审计字段及CREATED_DEPT；现有内网的TIMESTAMP、VARCHAR2长度和非空约束优先于新表默认规范。没有修改现有团组织表；该本地表字段长度比内网短，但考核字段兼容。

`db/twshyk_assessment_local_schema.sql` 仅供本地缺表时使用。夹具脚本通过元数据判断存在性，不重建已有表。

测试数据包括9个组织（含根节点及其他组织域）、54条会议记录，当前ORG_ROOT页面展示7个非根组织。专用ID与创建者均含 `TWSHYK_TEST` 标记。覆盖全部达标、完全缺会、部分缺会、多次会议、上下级独立、团小组会、空日期、跨年边界和跨组织域数据。

在当前PowerShell进程设置本地DJ库的 `PB_TEST_DB_PASSWORD`，再运行：

```powershell
./scripts/twshyk-assessment.ps1 build
./scripts/twshyk-assessment.ps1 seed
./scripts/twshyk-assessment.ps1 test
./scripts/twshyk-assessment.ps1 verify
```

`seed`先清理专用ID且创建者匹配的测试数据，再重建；重复执行不增加数量。`clean`仅清理这些测试行，不删除表，也不触碰其他数据。清理后可用`seed`恢复同一批测试数据。

`test`使用实际DM数据库、MyBatis映射及业务服务执行213项断言；补录与修改测试在事务中进行并回滚。测试需先seed，不能针对内网生产数据运行。数据库连接固定为本机127.0.0.1:5236，不在脚本中保存密码。

编译后需按项目运行规范重启Tomcat及Redis：
