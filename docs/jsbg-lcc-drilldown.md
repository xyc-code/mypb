# 举手报告统计下钻：内网接入

本次目标视图是内网已有的 `jsbg_lcc`。本地没有该视图，不能替内网发布配置。只复制统计页文件并不能完成筛选，必须完成下面的视图接入后再验收。

## 文件与入口

- 复制 `WebRoot/avicit/pb/jushoubaogao/JuShouBaoGaoStatistics.jsp`。
- 复制 `WebRoot/static/pb-modern/jushoubaogao/jushoubaogao.js` 和同目录新增的 `jushoubaogao-drilldown.js`。
- 入口为 `platform/eform/bpmsCRUDClient/toViewJsp/jsbg_lcc`。统计页传 `jbgDrilldown=1`、`jbgYear`、`jbgType`、`jbgState`，中文参数经过 URL 编码。
- 无 Java、数据库表结构或流程变更，不覆盖整个内网视图，也不修改平台公共脚本。

### 本次补丁的前提与回退

本包只交付 2026-09-24 本次下钻改动的三个运行文件，不是从已确认内网基线重新汇总的全模块升级。内网应已有举手报告统计页面及现有统计接口，并已具备 2026-09-21 的安全类型归并逻辑；如尚未部署该 Java 改动，先核对版本，不要把本包当成包含该改动的全量包。

覆盖前备份内网原统计 JSP、统计 JS，并导出 `jsbg_lcc` 当前已发布配置。回退优先恢复这些内网备份：恢复两个原文件，撤销本次新增的视图查询项及 JS 扩展引用、重新发布，删除本次新增的 `jushoubaogao-drilldown.js`，再强制刷新浏览器。包内“回退参考”仅保存本次修改前的本地两个文件，不代表内网版本；只有与内网覆盖前版本核对一致时才可使用。

本补丁不更改 Tomcat 配置。内网必须使用正式 BPM 状态：`pb.jbg.tempStatusMode` 不设置或设为 `false`；若修改了该 JVM 参数，重启后确认统计 JSON 中 `statusTemporary=false`、`statusBasis=BPM_CLIENT_HIST_PROCINST_V.BUSINESSSTATE_`。复制前端文件本身不需要 Java 编译。

## jsbg_lcc 视图配置

先备份当前已发布视图配置。在主流程表格的“查询区 → 高级查询”中保留原有查询项，并新增以下两个专用项。**数据字段标识和表单字段标识不是同一项**。

| 查询项名称 | 数据字段 | 表单字段标识 `formFiledID` | 控件 `formControl` |
|---|---|---|---|
| 统计创建时间 | 主表 `CREATION_DATE` | `JBG_CREATION_DATE` | 时间框 `dateTime` |
| 统计报告类型 | 主表 `BGLX` | `JBG_REPORT_TYPES` | 复选框 `checkbox` |

字段绑定使用设计器选出的主表字段及别名，不手写表别名。新查询项默认值留空。类型项沿用报告类型通用代码，选项值至少包含质量、安全、生产、技术、其他；安全的完整名称如字典已有则保留。

**当前本地平台的属性面板隐藏了复选框选项，但后端查询支持 `formControl="checkbox"`，按逗号分隔值生成 `IN` 条件。** 内网版本若同样没有复选框选项：先建“下拉框”类型项并选择报告类型通用代码，再在备份后的视图 XML 中，只将 `formFiledID="JBG_REPORT_TYPES"` 对应节点的 `formControl="select"` 改为 `formControl="checkbox"`，保留其它属性、节点和通用代码配置，再通过平台重新导入、发布。不能仅修改生成的 HTML；那不会改变服务端查询配置。重新发布后确认页面生成了 `name="JBG_REPORT_TYPES"` 的 checkbox。若内网版本不能生成该控件，停止接入，不使用文本模糊查询代替。

在视图设计器“JS文件扩展”中新增 `/pb/static/pb-modern/jushoubaogao/jushoubaogao-drilldown.js?v=20260924-1`，保留原有文件，保存并重新发布（应用上下文不是 `/pb` 时替换该前缀）。这是平台已有的文件扩展入口；不要把异步加载代码放进页面加载事件，否则可能漏掉第一次查询。生成页面应通过普通 script 标签加载扩展文件，浏览器首次列表请求必须已含下钻条件。

接入脚本只在 `jsbg_lcc` 的统计下钻链接中启用。普通菜单不带 `jbgDrilldown=1`，不会改变查询请求。不要修改现有流程权限、表单权限或数据权限。

## 条件与交互

- 报告数对应 `all`，已完成及闭环率对应 `ended`，处理中对应 `active`，未受理对应 `start`。
- 年份按主表创建时间，标准日期查询传年初 `00:00:00` 至年末 `23:59:59`。PB 审计字段为 DATE、精度到秒，与统计接口的“当年年初（含）至下一年年初（不含）”等价；不能绑定到发生时间 `FSSJ`。如内网改为带小数秒的 TIMESTAMP，应先调整日期筛选方案，不按此 DATE 前提验收。
- 总体不限制类型；安全传 `安全,安全（技安环保/保密/保卫/合规等）`，通过专用复选查询项匹配这两个精确值，其余类型精确匹配。
- 下钻页面锁定年份、类型、状态；高级查询的其他字段可继续缩小范围。重置、翻页、排序后仍保留统计范围。原报告类型字段回显所选类型；安全兼容字典里只有完整名称的情况。
- 下钻页面的快捷关键词查询禁用，使用高级查询。平台关键词查询与高级查询走不同的服务端分支，混用会绕过日期及类型条件。
- 柱条、数值标签、左侧指标名称均可点击；全零时仍保留五个指标名称，以便进入空列表。顶部卡片和月度图不增加跳转。
- 同一年份、类型、指标复用系统内页签；不同组合分别打开。直接单独访问统计页、没有门户页签 API 时，使用浏览器新页签。
- 查询项缺失、类型控件不正确或跳转参数非法时停止请求并显示错误，不降级成未筛选的全部记录。

## 验收

1. 以同一有权限账号测试六类（总体、质量、安全、生产、技术、其他）× 五项指标，共 30 个组合，核对网络请求中的 `param.bpmState`、`JBG_REPORT_TYPES`、`JBG_CREATION_DATE_START/END`。
2. 检查首次请求就含条件，分页、排序、附加高级查询、重置后条件仍存在；普通菜单打开不带这些下钻条件。
3. 安全同时包含两个历史值，不包含其他含“安全”字样的异常值。总体报告数包含其他流程状态及无流程记录（以视图原有数据源、权限允许展示的范围为准）。
4. 验证年初、年末最后一秒、相邻年份；零值可打开空列表；切换年份和类型后使用新条件，月度类型不影响工作进展跳转。
5. 已完成与闭环率打开相同记录集合。以真实 BPM 数据对账，不能用本地 `JBG_TEST_STATUS` 演示数据替代。统计接口按报告的最新流程实例聚合；若内网视图的实例关联或数据权限口径不同，先记录并核对差异，不扩大权限或擅自调整统计。
6. 删除一个专用查询项或传非法年份时，确认出现接入错误且不发送未筛选查询。

本地浏览器回归使用真实 jQuery、jqGrid、ECharts 和模块脚本，但用模拟列表接口验证请求与交互；内网真实视图、字段绑定、发布结果和最终记录数量仍须联调确认。
