- 开始日取 DYN_YZBYTSKHRQ.KH_MONTH/KH_DAY；当天起，无主表扣0.1、缺里程碑补足3条每条0.1；实际超过3条全部考核。

- 一组织一年一份主表；重复、缺计划日期等显式异常，不任取一份或当零分。
- 用户确认月度仅归属月扣一次：缺项归开始月，里程碑归max(开始日,计划完成时间+24小时)的月份；跨年计划按实际到期归属。
- 补算按运行时现状，缺项恢复需重算原月；日期跨月变更需重算旧、新月。不新增生产流水表、不自动回填全部历史。
